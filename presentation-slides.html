Problem & Paradigm Shift

The Memory Search Gap in Personal Photo Libraries

Human memory is episodic and fuzzy, whereas traditional search engines expect rigid keywords.

cancel Traditional Keyword Photo Search
  • • Fails when users forget exact dates, filenames, or precise place names.
  • • Returns flat, un-clustered 100+ photo grids requiring manual scrolling.
  • • Cannot ground ambiguous queries like "that small café in Goa".
check_circle Google Photos Memory Search Agent
  • • Deconstructs natural language into spatial, temporal, people, and visual clues.
  • • Partitions candidate hits into spatio-temporal event clusters automatically.
  • • Proactively asks clarification questions when queries are ambiguous.

Phase Technical Objective Implementation Highlights & How We Achieved It
01 Datasets & Ground-Truth Created mockPhotoLibrary.ts with 520+ photo records across 14 event clusters (Diwali, Taj Mahal, Kashmir, Kerala, Tokyo, Goa), 128d vector embeddings, GPS EXIF, bounding boxes & 15 scenario benchmark suite.
02 NLU Memory Clue Extractor Built memoryClueExtractor.ts utilizing Gemini 1.5 Flash parsing natural language queries into spatial location, place category, temporal range, people tags & visual attributes with status preservation.
03 Hybrid Search & Clustering Built hybridRetrievalEngine.ts & contextualClusterEngine.ts fusing 128d cosine vector distance, GPS proximity, OCR matching & spatio-temporal clustering (<2ms latency, 100% precision).
04 Clarification & Evidence Stage Built clarificationPolicyEngine.ts calculating candidate entropy (H > 0.75) to trigger 1-click targeted questions. Built matchEvidenceExplainer.ts generating bounding boxes & OCR text groundings.
05 6-Screen UI & Clue Matrix Built responsive Material 3 client app (app.ts, Screen1 to Screen7) with interactive toggleable clue pills, real-time weight sliders, custom location adder & All Photos timeline across 520+ photos.
06 Testing, Telemetry & Vercel Implemented telemetry logging (state.ts), 4 automated validation test suites, 0-error TypeScript compilation, 209ms Vite production build & Vercel deployment setup (vercel.json).
